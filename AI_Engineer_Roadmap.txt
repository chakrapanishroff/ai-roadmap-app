 PROJECT LADDER (build these - put on GitHub)
----------------------------------------------------------
Beginner
 1. House price / churn prediction (scikit-learn, Kaggle dataset)
 2. Image classifier with PyTorch (CIFAR-10 / your own images)
Intermediate
 3. Implement a neural net + backprop from scratch with NumPy
 4. Fine-tune a small LLM (LoRA) on a custom dataset
 5. RAG chatbot over your own PDFs with citations + evals
Advanced
 6. Build a GPT from scratch (Karpathy-style) and train on small data
 7. Tool-using agent with MCP servers + eval harness + tracing
 8. Deploy an LLM with vLLM behind FastAPI + Docker, load test it,
    measure latency/throughput/cost
Hardcore
 9. Reproduce a paper (e.g., LoRA, FlashAttention-lite, DPO)
10. Write a custom CUDA/Triton kernel and benchmark vs PyTorch
11. Open-source contribution to transformers / vLLM / langchain / etc.
12. Kaggle medal or a published blog post breaking down a paper

Months 5-6   : Deep learning + PyTorch

----------------------------------------------------------
 HABITS OF TOP AI ENGINEERS
----------------------------------------------------------
- Read 1-2 papers a week; implement one per month.
- Code every day; reimplement things from scratch at least once.
- Always measure: build evals before building features.
- Ship publicly: GitHub, blog posts, HF Spaces, X/LinkedIn.
- Learn the stack end to end: data -> training -> eval -> serving -> monitoring.
- Stay current: the field moves weekly. Follow the news sources above.
